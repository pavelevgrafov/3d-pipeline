# Задача (шаг 0)

Исходное описание, с которого начался этот прогон. Приведено как образец того,
насколько подробным имеет смысл быть на нулевом шаге.

## Предмет

Накладные наушники премиум-класса. Оголовье — плоская дуга с кожаной
накладкой сверху и металлической пластиной снизу. По бокам — вертикальные
кронштейны, уходящие в чашки. Чашки цилиндрические, неглубокие; снаружи
на каждой — плоский полированный диск с гравированной эмблемой. Амбушюры
кожаные, с мягким валиком.

## Материалы

| Часть | Материал |
|---|---|
| накладка оголовья | кожа с выраженным зерном |
| амбушюры | кожа мельче зерном, мягче |
| пластина, кронштейны, диски, эмблема | металл |
| корпус чашек | матовый пластик либо лак |

## Кадр

Тёмная рекламная подача: чёрный фон, узкие полосы бликов по рёбрам,
световое пятно справа. Вертикальный кадр под разворот. Резкой должна быть
эмблема на ближнем диске; ближняя чашка и дальняя дужка уходят в размытие.

Референс по настроению: студийная съёмка автомобильной акустики — предмет
почти сливается с фоном, читается только контуром и бликами.

## Что выяснилось по ходу

Пункты, которых в исходном описании не было, но без которых кадр не получался.
Они и есть содержание контрольных точек — см. [README.md](README.md).

* Ракурс: угол выбран не с листа, а вручную во вьюпорте, и оказался
  ортографическим — перспектива ломала прямоту дужки.
* Плоский полированный диск остаётся **чёрным пятном** при любой яркости
  общего света: ему нужен отражатель, поставленный по зеркальному лучу.
* Фон нельзя поднимать вместе с предметом — иначе теряется главное, ради
  чего вся подача. Отсюда источники, светящие только в блик
  (`visible_diffuse=False`).
