# Пример: наушники

Прогон, доведённый до конца, — тот самый, из которого вырос весь пайплайн.
Здесь он воспроизводится **целиком из кода**: `.blend` в репозитории нет,
сцена собирается с нуля каждый раз.

```bash
blender -b --python make.py -- /tmp/hp both       # герой + крупный план
blender -b --python make.py -- /tmp/hp preview    # быстрый взгляд, ~5 с
blender -b --python ../../lib/post.py -- /tmp/hp/hero_night_chrome.exr /tmp/hp/graded.png
```

## Файлы

| Файл | Шаг | Что внутри |

## Утверждённые числа

Всё, что пользователь выбрал на контрольных точках, лежит в `shot.py`
константами — и только там:

```python
CAM_QUAT      = (0.27962, 0.416601, 0.718235, 0.482073)   # снят с вьюпорта
CAM_EYE       = (4.6535, 2.5828, -2.4749)
VIEW_DISTANCE = 5.6757        # орто, перспектива ломала прямоту дужки
MATERIAL_SET  = 3             # Night Chrome
RES           = (900, 1200)   # вертикаль 3:4 под разворот
FILL          = 0.86          # плотно, предмет распирает кадр
OFFSET        = (0.04, 0.05)  # предмет стоит по диагонали
FSTOP         = 4.0
```

Из них `frame.fit()` считает охват кадра **3.3246** — это число печатается
в лог каждого рендера и служит контрольной суммой: если оно изменилось,
изменился кадр.

## Два кадра

**Герой** — 900×1200, 320 сэмплов, фокус на эмблеме ближнего диска при f/4:
ближняя чашка и дальняя дужка уходят в размытие.

**Крупный план** — 1100×1100, охват 1.05, кадр сдвинут прямо на эмблему.
Диафрагма зажата до **f/9**: на таком масштабе прежнее размытие съело бы саму
деталь, ради которой кадр и снимается.

Оба вместе считаются около 56 секунд. Цветокоррекция по готовому EXR —
около секунды, поэтому грейд правится сколько угодно раз.

## Чему научил этот прогон

Три вещи, которые нельзя было угадать и которые пришлось поймать рендером —
они и стали частью библиотеки:

**Плоский полированный диск остаётся чёрным пятном** при любой яркости
общего света. Зеркалу нужно отражать что-то конкретное, а отражатель должен
стоять не за предметом, а **по зеркальному лучу** — то есть позади камеры.
Отсюда `lighting.mirror_board()`.

**Фон нельзя поднимать вместе с предметом.** Если осветить рёбра обычным
источником, вместе с ними поднимется и фон, и вся тёмная подача рассыплется.
Отсюда источники с `visible_diffuse=False` — светят только в блик.

**Диафрагма в орто работает не как в фотографии.** Радиус апертуры равен
`lens/(2·fstop)/1000` и от дистанции не зависит; f/1.2 даёт кашу. Рабочий
диапазон — 2.5…5.0 на общем плане и 8…10 на крупном.
