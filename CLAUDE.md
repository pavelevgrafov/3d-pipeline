# 3d-pipeline

Пайплайн для рекламных изображений предмета в Blender по описанию и референсам.
Пользователь не работает в GUI: он смотрит на картинку с вариантами и называет
номер. Всё остальное — код.

Документация: [GUIDE.md](GUIDE.md) — шаги и контрольные точки,
[LIMITS.md](LIMITS.md) — чего пайплайн не умеет.

## Структура

| Path | Purpose |
|---|---|
| `lib/` | библиотека, **предметно-независимая** — ничего про конкретный объект |
| `template/` | заготовка нового проекта: `build`, `sets`, `shot`, `make` |
| `tests/smoke.py` | сквозной прогон на тестовой сцене |
| `check.py` | одна команда, проверяющая репозиторий целиком |

## Правила

**Проверять рендером, а не рассуждением.** Превью — 5 секунд, сетка вариантов —
9. Посмотреть всегда быстрее, чем обосновать. Ни одно утверждение про свет,
материал или кадр не идёт пользователю без картинки.

**Утверждённые числа — в код.** Ракурс, номер набора, охват кадра живут
константами в `shot.py`, а не в `.blend`: файл мог быть сохранён до утверждения.

**После правки `lib/` — `python3 check.py`.** Обязательно, не по настроению.
Библиотека общая, и поломка в ней тихо ломает все проекты.

**В `lib/` не попадает ничего предметного.** Имена объектов, слоты материалов,
конкретные наборы — в проекте, не в библиотеке. Проверка: тестовая сцена
в `smoke.py` намеренно не похожа на заготовку ни формой, ни масштабом.

**Числа в долях охвата кадра.** Свет и композиция масштабно-инвариантны;
абсолютные размеры в библиотеке — ошибка.

## Грабли, проверенные ценой перерендеров

| | |
|---|---|
| `blender -b` без файла | грузит СТАРТОВУЮ сцену с кубом и лампой → `scene.reset()` первой строкой |
| `snap_to_viewport()` в фоне | падает намеренно; раньше молча отдавал стартовый ракурс |
| источники света — меши | в габариты не попадают только по `visible_camera` |
| свой `render.py` рядом со скриптом | перекроет `lib/render.py` → пульт называется `make.py` |
| орто + DOF | апертура = `lens/(2·fstop)/1000`, от дистанции не зависит; рабочий диапазон 2.5…5.0 |
| Blender 5 API | multilayer EXR — через `media_type`; компоузер — `scene.compositing_node_group`, ноды `Composite` нет; движок снова `BLENDER_EEVEE` |

## Команды

```bash
python3 check.py                                        # проверка репозитория
blender -b --python template/make.py -- /tmp/t preview
blender -b --python template/make.py -- /tmp/t final
blender -b --python lib/post.py -- in.exr out.png vignette=0.3
```
