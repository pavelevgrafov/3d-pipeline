# Заготовка нового проекта

Скопируйте эту папку рядом с собой и правьте четыре файла. Заготовка сразу
рабочая: собирает корпус с полированной накладкой и ободком — типовой
продуктовый предмет, — так что все шаги можно прогнать до того, как вы
что-то поменяли, и увидеть, как это выглядит.

```bash
cp -r template ~/my-object
cd ~/my-object
blender -b --python make.py -- /tmp/my preview
```

## Четыре файла

| Файл | Шаг | Что править |
|---|---|---|
| `build.py` | 1 | форма: параметры в начале файла, потом содержимое `build()` |
| `sets.py` | 3 | наборы материалов, 4–6 штук |
| `shot.py` | 2, 4 | утверждённые числа: ракурс, номер набора, кадр, свет |
| `make.py` | пульт | обычно не трогают |

## Порядок работы

```bash
blender -b --python make.py -- /tmp/my angles     # шаг 1: лист ракурсов
blender -b --python make.py -- /tmp/my looks      # шаг 3: лист материалов
blender -b --python make.py -- /tmp/my light      # шаг 4: варианты света
blender -b --python make.py -- /tmp/my preview    # быстрый взгляд между правками
blender -b --python make.py -- /tmp/my final      # шаг 5: PNG + EXR + .blend

blender -b --python ../lib/post.py -- /tmp/my/final.exr /tmp/my/graded.png
```

Что происходит на каждом шаге и что от вас требуется — [GUIDE.md](../GUIDE.md).

## Что нужно знать, прежде чем править

**Имена объектов — это интерфейс.** `build.py` называет объекты `Body`, `Face`,
`Ring`; по этим именам `sets.py` раскладывает материалы через `OBJECTS`.
Переименовали в одном месте — правьте и в другом, иначе материал молча
не применится.

**`face_world()` и `face_normal()` — ключевая точка предмета.** Первая
возвращает точку, которая обязана быть резкой и подсвеченной (шильдик, кнопка,
горлышко, циферблат — в заготовке это центр накладки); вторая — нормаль
плоской глянцевой детали, по ней ставится отражатель. Верните оттуда своё.

**Не называйте свои файлы как модули библиотеки.** Каталог скрипта стоит
в `sys.path` раньше `lib/`, поэтому файл `render.py` рядом перекрыл бы
`lib/render.py`. Отсюда и название `make.py`.

**Начинайте с `scene.reset()`.** `blender -b` без файла грузит стартовую
сцену — с кубом и лампой, и оба честно попадут в кадр. В `make.py` это уже
сделано.

## Настройки по умолчанию

`shot.py` идёт с перспективной камерой, квадратным кадром 1080×1080
и `FILL = 0.78` — предмет с воздухом, каталожно. Свет — тёмный рекламный
набор `editorial_dark`. Для матового или светлого предмета замените его
на `world_gradient()` + `three_point()`: `editorial_dark` выверен на тёмном
глянце и на матовом даст плоскую серую картинку (см. [LIMITS.md](../LIMITS.md)).

Ракурс по умолчанию задан углами (`USE_VIEWPORT = False`). Если хотите
крутить мышью — соберите сцену в открытом Blender, вызовите
`camera.snap_to_viewport()`, перенесите возвращённые числа в `CAM_QUAT`,
`CAM_EYE`, `VIEW_DISTANCE` и поставьте `USE_VIEWPORT = True`.
